# Reporting a security vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ParkPawapon/reunite/security/advisories/new) to report an issue to the repository owner. Include the affected commit, reproduction steps, and impact. Replace credentials and personal information with synthetic examples.

Use the `main` branch to check whether the issue still reproduces. Repository changes follow the review and CI controls described in the [contribution conventions](docs/SYSTEM_CONVENTIONS.md).
